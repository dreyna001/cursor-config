companion, with the [application-specific adaptation standard](../../investigation-desk-ui/references/visual-adaptation.md).

and removed. This path remains a compatibility entry point for existing callers;
it does not define a separate theme.

Strongly prefer the selected palette, Public Sans typography hierarchy, density,
spacing, surfaces, controls and progressive disclosure for new enterprise UI and
authorized substantial redesigns. Source-inspector B is the selected compact
source pattern, not a prescribed application workflow. Adapt to actual tasks;
retain necessary viewers, editors, approvals, drafts, complete evidence, exact
citations and the established accessible component stack. Explicit branding wins
and unrelated local fixes remain local. The investigation-desk-ui workflow skill
remains explicit-only. No existing application is changed by this documentation.

## Shared UI change completion

Approved shared UI changes are not complete until the versioned baseline,
its visual companion, all three apps (six frontends), this configuration
repository's reference bundle, and the permanent local baseline are synchronized.
Follow the baseline's “Keeping one baseline” procedure, record app-specific
exceptions and validation, and preserve newer approved behavior and styling.
If any part cannot be updated or verified, report the remaining drift explicitly.


On native Windows, resolve `$HOME/.agents/ui-baseline/` as `%USERPROFILE%\.agents\ui-baseline\`.
